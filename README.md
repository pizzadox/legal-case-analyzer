# Система Управления Уголовным Делом

## Обзор

Система управления уголовным делом — это веб-приложение для анализа и управления материалами уголовных дел Российской Федерации. Система позволяет загружать документы дела, автоматически распознавать и извлекать ключевые данные (участники, эпизоды, статьи УК) с помощью ИИ, и организовать всю информацию в удобном интерфейсе.

## Функциональность

### Основные возможности
- **Загрузка документов**: PDF, DOC, DOCX, TXT, RTF, изображения, XLS/XLSX, ODT/ODS, CSV (до 500 МБ)
- **Автоматическое распознавание**: ИИ-анализ загруженных документов с извлечением:
  - Участников дела (ФИО, роль, контекст)
  - Эпизодов/преступлений (описание, дата, тяжесть)
  - Статей УК РФ (код, описание, категория)
  - Резюме документа и тип классификации
- **Фоновая обработка**: Документы обрабатываются в фоновом режиме, можно переходить на другие страницы
- **Отображение прогресса**: Визуальная очередь обработки с процентом выполнения
- **Переключение дел**: Создание и переключение между несколькими уголовными делами
- **Экспорт данных**: CSV и PDF экспорт документов

## Архитектура

### Технологический стек
- **Фронтенд**: Next.js 16 (App Router) + TypeScript 5 + Tailwind CSS 4 + shadcn/ui
- **Бэкенд**: Prisma ORM (SQLite) + Next.js API Routes
- **Состояние**: Zustand (клиент) + TanStack Query (сервер)
- **ИИ**: z-ai-web-dev-sdk (LLM для анализа, VLM для чтения PDF/изображений)
- **Визуализация**: Recharts + Framer Motion

### Микросервисы
- **doc-processor** (порт 3005): Фоновая обработка документов
  - Опрос базы данных каждые 5 секунд для новых документов
  - Извлечение текста (PDF через VLM, изображения через VLM, текстовые файлы напрямую)
  - ИИ-анализ через LLM с извлечением структурированных данных
  - Создание записей Person, Episode, Article и связей в базе данных
  - API статуса обработки: `GET /api/status?caseId=xxx`

### Маршрутизация
- Основное приложение: порт 3000 (Next.js)
- Шлюз Caddy: порт 81 → перенаправление на 3000 или 3005 (по XTransformPort)
- Микросервис обработки: порт 3005

## Установка и запуск

### Требования
- Node.js 18+ / Bun 1.0+
- npm или bun

### Запуск
```bash
# Установка зависимостей
bun install

# Инициализация базы данных
bun run db:push

# Запуск основного приложения
bun run dev

# Запуск микросервис обработки (отдельно)
cd mini-services/doc-processor
bun install
bun run db:push
bun run dev
```

### Проверка качества кода
```bash
bun run lint
```

## Обработка документов

### Пайплайн обработки
1. **Загрузка**: Файл сохраняется в `uploads/`, создаётся запись Document (status: pending)
2. **Опрос**: doc-processor каждые 5 сек проверяет очередь
3. **Извлечение текста**: 
   - PDF → VLM (визуальное распознавание)
   - Изображения → VLM (описание + OCR)
   - DOCX/TXT → прямое чтение
4. **ИИ-анализ**: LLM получает извлечённый текст и возвращает структурированный JSON с:
   - Резюме документа
   - Тип документа (обвинение, показание, протокол, экспертиза...)
   - Участники (ФИО, роль, контекст)
   - Эпизоды (описание, дата, тяжесть, статьи)
   - Статьи УК РФ (код, описание)
5. **Сохранение**: Создаются записи Person, Episode, Article + связи в БД
6. **Обновление**: Document status → completed, все разделы автоматически обновляются

### Мониторинг прогресса
- Документы раздел показывает панель прогресса с:
  - Общий процент обработки
  - Список каждого документа с статусом (в очереди / обработка / готово / ошибка)
  - Автообновление каждые 5 секунд
- Можно переходить на другие страницы — обработка продолжается в фоне
