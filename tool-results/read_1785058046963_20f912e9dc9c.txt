     1→# Criminal Case Management System - Worklog
     2→
     3→## Project Overview
     4→Building a comprehensive criminal case management application for analyzing materials of a criminal case (уголовное дело). The system includes:
     5→- PDF document upload and text extraction with queue processing
     6→- AI-powered analysis extracting persons, places, articles, episodes
     7→- Cross-reference search by links in text
     8→- Search by date, document, person, article
     9→- Legal compliance checking against Russian Federation norms
    10→- Kolesnichenko defense line analysis
    11→- AI Q&A system for case-related questions
    12→- Participant visualization with guilt status and forecasts
    13→- Document management interface
    14→
    15→## Tech Stack
    16→- Next.js 16 with App Router
    17→- TypeScript 5
    18→- Tailwind CSS 4 + shadcn/ui
    19→- Prisma ORM (SQLite)
    20→- z-ai-web-dev-sdk (LLM, VLM for document analysis)
    21→- Zustand for client state
    22→- TanStack Query for server state
    23→- Recharts for visualizations
