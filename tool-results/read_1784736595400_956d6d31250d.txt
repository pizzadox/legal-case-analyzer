     1→     1→# Criminal Case Management System - Worklog
     2→     2→
     3→     3→## Project Overview
     4→     4→Building a comprehensive criminal case management application for analyzing materials of a criminal case (уголовное дело). The system includes:
     5→     5→- PDF document upload and text extraction with queue processing
     6→     6→- AI-powered analysis extracting persons, places, articles, episodes
     7→     7→- Cross-reference search by links in text
     8→     8→- Search by date, document, person, article
     9→     9→- Legal compliance checking against Russian Federation norms
    10→    10→- Kolesnichenko defense line analysis
    11→    11→- AI Q&A system for case-related questions
    12→    12→- Participant visualization with guilt status and forecasts
    13→    13→- Document management interface
    14→    14→
    15→    15→## Tech Stack
    16→    16→- Next.js 16 with App Router
    17→    17→- TypeScript 5
    18→    18→- Tailwind CSS 4 + shadcn/ui
    19→    19→- Prisma ORM (SQLite)
    20→    20→- z-ai-web-dev-sdk (LLM, VLM for document analysis)
    21→    21→- Zustand for client state
    22→    22→- TanStack Query for server state
    23→    23→- Recharts for visualizations

    53→    53→  1. /api/case/upload (POST) - Multi-file PDF upload with FormData, file saving to download dir, Document + ProcessingQueue creation
    54→    54→  2. /api/case/documents (GET) - Document listing with status/type/date filters, includes persons, episodes, articles, queue info
    55→    55→  3. /api/case/process (POST) - AI document processing: VLM for PDF text extraction, LLM for structured analysis (persons, locations, articles, episodes, cross-references), database record creation/update for all extracted entities and junction tables
    56→    56→  4. /api/case/persons (GET) - Person listing with role/isKolesnichenko filters, includes documents, episodes, articles, defense lines, guilt assessments
    57→    57→  5. /api/case/episodes (GET) - Episode listing with severity/status filters, includes persons, locations, articles, documents, guilt assessments
    58→    58→  6. /api/case/search (POST) - Cross-reference search with query + filters (date, person, article, document, location), searches across documents, persons, episodes, articles, cross-references
    59→    59→  7. /api/case/qa (POST) - AI Q&A: gathers context from DB (documents, persons, episodes, articles, cross-refs), uses LLM for answer, creates ChatMessage with linked documents/persons
    60→    60→  8. /api/case/defense (POST) - Kolesnichenko defense analysis: finds isKolesnichenko person, gathers all related data, uses LLM for strategic defense analysis, creates DefenseLine records
    61→    61→  9. /api/case/compliance (POST) - Legal compliance checking: article applicability, procedure compliance, evidence admissibility, statute of limitations checks via LLM, creates LegalCompliance records
    62→    62→  10. /api/case/dashboard (GET) - Dashboard statistics: aggregated counts for all entities, status/type groupings, queue status, guilt assessments summary, defense lines summary, compliance summary, recent documents
